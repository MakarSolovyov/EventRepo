# EventRepo

## Описание проекта

Приложение ASP.NET Core Web API для управления событиями (CRUD) с хранением данных в памяти. Проект использует ConcurrentDictionary для потокобезопасного хранения событий и возвращает унифицированные ответы.
## Структура проекта

- Controllers/ - Контроллеры API
- Interfaces/ - Интерфейсы сервисов
- Models/ - Модели
- Models/DTO/ - DTO-модели
- Services/ - Реализация сервисов
- ApiResult.cs - Базовые классы ответа API
- Program.cs - Точка входа и конфигурация


## Запуск проекта

Для запуска требуется .NET SDK 10. Находясь в директории проекта, выполнить следующие команды:

```bash
# компиляция проекта и сборка зависимостей
dotnet build

# запуск в режиме разработки с указанием профиля
dotnet run --launch-profile https
```

После запуска приложение доступно по адресу: https://localhost:7162/swagger

## Документация API

#### Получение данных по всем событиям

```https
  GET /events
```

| Parameter | Type     | Description                       |
| :-------- | :------- | :-------------------------------- |
| `title`      | `string`   | Название (частичное, регистронезависимое) |
| `from`      | `DateTime`   | Время начала события |
| `to`      | `DateTime`   | Время завершения события |
| `page`      | `int`   | Номер текущей страницы (начиная с 1) |
| `pageSize`      | `int`   | Количество элементов на текущей странице |

- 200 OK — ApiResult<PaginatedResult<Event>> со списком событий.

#### Получение данных события по идентификатору

```https
  GET /events/{id}
```

| Parameter | Type     | Description                       |
| :-------- | :------- | :-------------------------------- |
| `id`      | `Guid`   | **Required**. Идентификатор события |

- 200 OK — ApiResult<Event> с деталями события.
- 404 Not Found — событие не найдено.

#### Добавление нового события

```https
  POST /events
```

| Parameter | Type     | Description                       |
| :-------- | :------- | :-------------------------------- |
| `eventDTO`      | `EventDTO`   | **Required**. Данные по событию в JSON формате |

- 201 Created — событие создано.
- 400 Bad Request — ошибка валидации.
- 409 Conflict — событие с таким id уже существует.

#### Обновление информации по событию

```https
  PUT /events/{id}
```

| Parameter | Type     | Description                       |
| :-------- | :------- | :-------------------------------- |
| `id`      | `Guid`   | **Required**. Идентификатор события |
| `eventDTO`      | `EventDTO`   | **Required**. Данные по событию в JSON формате |

- 204 No Content — событие обновлено.
- 400 Bad Request — ID в маршруте и теле не совпадают, либо ошибка валидации.
- 404 Not Found — событие не найдено.

#### Удаление данных события по идентификатору

```https
  DELETE /events/{id}
```

| Parameter | Type     | Description                       |
| :-------- | :------- | :-------------------------------- |
| `id`      | `Guid`   | **Required**. Идентификатор события |

- 204 No Content — событие удалено.
- 404 Not Found — событие не найдено.
## Особенности

- Данные хранятся в памяти (ConcurrentDictionary) и не сохраняются между перезапусками приложения.
- Swagger UI доступен только в режиме Development.
- XML-документация включена в Swagger.
- Для HTTPS включён редирект (UseHttpsRedirection).
